# Integração e Conformidade PIX

- **Chave DICT**: Normalização automática sem pontuação para CNPJ (14 caracteres) e formato internacional (+55...) para telefone.
- **Padrão EMVCo**: Payload montado com tags TLV e cálculo rigoroso de CRC16-CCITT (0xFFFF).
