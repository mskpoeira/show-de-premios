# Política Estrita de Privacidade de Dados Pessoais

1. **Princípio do Privilégio Mínimo**:
   - Usuários não autenticados não têm acesso a nenhuma informação de identificação pessoal (PII).
   - Dados de compradores nunca são incluídos em payloads públicos ou códigos QR.
2. **Telão Público**:
   - É terminantemente proibido exibir dados de compradores ou números de cartelas vencedoras no telão.
