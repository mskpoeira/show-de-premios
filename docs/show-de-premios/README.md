# Show de Prêmios — Sistema Oficial de Gerenciamento e Sorteios

O **Show de Prêmios** é um sistema completo, autônomo e isolado para gestão de eventos beneficentes, vendas de cartelas físicas e online, pagamentos PIX automatizados, motor de pontuação em tempo real e telão de alta definição para eventos de bingo e premiação.
