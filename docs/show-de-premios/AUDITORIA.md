# Trilha de Auditoria e Logs

O Show de Prêmios mantém duas trilhas de auditoria separadas:
1. **audit_logs**: Ações administrativas, login, alterações de preços, configurações e sorteios.
2. **ticket_access_logs**: Consultas pontuais a dados pessoais de compradores, registrando operador, data, hora, método, IP e dispositivo.
