# Gestão e Emissão de Cartelas

- **Código de Conferência**: 8 caracteres alfanuméricos sem confusões visuais (ex: `K7P4-X2MQ`).
- **Token do QR Code**: Token aleatório de 128 bits de entropia (`32 caracteres hexadecimais`).
- **Impressão A4**: Layout profissional configurável para 1, 2 ou 4 cartelas por página A4 (padrão 2 por página com linha de corte e QR legível).
- **Segunda Via / Reimpressão**: Mantém rigorosamente os mesmos números, código e QR original, incrementando o contador de impressões para auditoria.
